如何完成一个季度

1

先读输入

查看比赛规则、本企业现金与资产、公开订单，以及规则允许购买的对手情报。其他企业的私有决策默认不可见。

2

提交经营与申领方案

这是获单前的经营计划：安排融资、研发认证、厂房产线、原料、广告，并申领公开订单。所有企业提交后，裁判统一处理订单冲突与分配。

3

提交获单后履约方案

订单结果公布后，只依据本企业实际获单重新安排贷款、采购、生产和交付。提交后由环境独立判定现金流、违约、报表和破产。

4

让 Agent 辅助，而不是替你盲交

选择稳健、平衡或增长风格。多模块 Agent 会联合检查资金、资格、订单收益、产能与风险，生成可读建议；你可以增删和修改后再提交。

系统输入

规则、本企业私有状态、公开订单、可购情报、当前阶段、风险偏好。

系统输出

可读决策建议、风险提示、订单分配结果、新企业状态、报表、排名与复盘建议。
