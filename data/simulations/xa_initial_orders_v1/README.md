# XA 初始可见与预分配订单场景

本目录是在固定 XA 参数模拟比赛之上的显式场景扩展，用于测试 Agent 在比赛开始时已经存在公共订单和私有已获订单的情况。真实 XA 资料记录 `first_year_has_orders=false`，因此这里的初始订单是 `simulated_scenario_override`，不是正式 XA 事实。

`SIM_XA_INITIAL_seed_20260809/` 与固定基准使用相同 XA 参数、相同候选结算服务、相同第二年至第五年订单种子和相同编号 Agent 策略。唯一主要场景变化为：

- Y1Q1 新增 54 个本地 P1 订单。
- 18 个订单随机预分配给 18 家不同企业，进入各自私有 `assigned_orders`，分配结果对全场公开。
- 另外 36 个订单在第一次观测中对所有 Agent 可见，可以参与选单或竞单。
- 预分配和公共订单均具有足够的生产交付期限，订单内容和分配由种子 `20260811` 决定。

比赛完整运行 27 家企业、20 个季度，共 850 个订单。最终产生 71 次订单分配和 71 次交付，其中初始订单分配 25 个：18 个预分配、7 个从公共池竞争获得；没有订单违约，没有企业破产。

比赛式目录同时包含 `1.xlsx~6.xlsx` 年度全局公开文件、27 个企业九 Sheet 文件、规则、全局订单、最终排名，以及 XLSX 回读后的统一 JSONL。
