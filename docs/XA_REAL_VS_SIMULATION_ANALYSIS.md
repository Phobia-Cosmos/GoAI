# 真实 XA 与模拟比赛结果分析

本报告比较三组数据：真实 XA 省赛赛场、固定 XA 参数且第一年无订单的标准模拟、固定 XA 参数并增加 Y1Q1 初始订单的场景模拟。两场模拟使用相同随机种子 `20260809`、相同第二年至第五年订单和相同编号 Agent 策略，因此它们之间可以近似视为初始订单场景的配对比较；真实 XA 与模拟之间只能做结构和结果分布比较，不能解释为严格因果实验。

真实 XA 中，561/796 个订单有归属，约占 70.5%；544 个已交，另有 11 个违约和 6 个未交。9/27 家企业破产，说明真实参赛者普遍采用更高风险、更高资本占用和更高发展投入的策略。冠军 XA07 的所有者权益为 1050、发展潜力为 261、正式得分为 3791；排名前 3 的得分均超过 2500。

固定模拟中只分配了 46/796 个订单，约占 5.8%，但全部交付且没有破产。所有 Agent 的发展潜力均为 18，主要由本地市场、P1、小厂房和手工线组成，排名几乎完全由少量订单利润和终局权益决定。它验证了全局环境、订单冲突、生产交付、财务状态机、年度三表和终局排名能够闭环运行，但当前现金约束基线明显过于保守，不能复现真实 XA 的策略强度和得分分布。

初始订单场景中，第一次观测对所有 Agent 显示 36 个公共订单；18 家企业各有 1 个私有预分配订单，另外 9 家没有预分配订单。最终 25 个初始订单被分配并全部交付，其中 18 个来自预分配、7 个来自公共池；第二年至第五年又分配并交付 46 个订单。总分配量由 46 提升到 71，平均权益由 273.80 提升到 302.97，平均得分提高 34.43，约提高 10.7%。27 个配对企业中 19 个得分提高、8 个下降。

预分配订单并不等于必然优势。18 家预分配企业平均得分变化为 +18.93，9 家未预分配企业平均变化为 +65.42。未预分配企业可以从 36 个公共订单中选择更匹配利润和产能的订单；预分配企业则必须优先履行随机给定的订单，并失去部分后续择单机会。企业 03 因初始场景得分增加 120.36、排名由第 9 升至第 2；企业 23 得分下降 73.16、排名由第 7 降至第 26。这证明初始订单的价值取决于订单利润、交期、产能匹配和机会成本，而不是“有订单”这一字段本身。

当前结论是：模拟环境已经可以作为全局裁判环境使用，初始订单可见性和随机预分配也已经成为可配置场景；但基线 Agent 还不能代表真实优秀企业。下一阶段应增加扩张型、运营型、融资型和高风险型策略，使产品、市场、ISO、厂房和产线组合产生差异，并让一部分策略在订单压力下破产。随后再用真实 XA 的得分、权益、发展潜力、订单覆盖率和破产率对模拟策略分布做校准，而不是直接调整正式 XA 参数。

## 2026-08-11 XA 企业群体校准实验

新增 `XARealisticPopulationPolicy` 和 `scripts/run_xa_population_calibration.py`。实验固定使用 XA 参数，不复制企业终局分数、订单归属、破产标签或未来决策路径；订单内容从真实 XA 的年度、产品、市场、数量、ISO、价格、交期和账期联合分布重采样，并清除全部终局标签。订单 ISO 已统一为 ISO9000、ISO14000 和双认证集合，避免把 `9K 14K` 错当成单项资格。

三种订单种子 `20260811`、`20260812`、`20260813` 均运行 27 家企业和完整 20 季。为了先校准群体风险分布，18 家企业采用现金安全基线并分阶段增加产品、市场和产能，9 家采用高杠杆扩张策略。三场均得到 18 家存续、9 家破产，存续率与真实 XA 的 66.67% 一致，全部企业资产负债平衡，且没有状态机动作拒绝。这说明模拟器可以稳定产生真实数量级的破产分布，而不是只能生成全员存续。

但经营结果仍未接近真实 XA。三种子均值如下：存续企业得分 276.43，对比真实 1569.39；全体企业破产记零得分 184.29，对比真实 1046.26；存续企业权益 211.02，对比真实 584.22；发展潜力 31.00，对比真实 149.67；分配订单 96.67，对比真实 561；交付订单 22，对比真实 544；未分配订单 699.33，对比真实 235；平均已完成产线 2.00，对比真实 8.83。

因此当前差距可明确拆分：破产数量、会计平衡和完整 20 季结算已经达到群体级校准目标；低分主要来自 Agent/对手策略接单过少、产线扩张不足、产品市场覆盖不足和订单吞吐过低。模拟器仍有一个需要候选验证的阶段语义：订单在经营动作后分配，经验订单实验暂用两季度宽限，保证新分配订单至少获得一次完整生产机会。它不能被宣称为已确认的正式 XA 隐藏规则。

产物位于 `data/experiments/xa_population_calibration_v1/`。下一阶段不再优先调整正式参数或直接放大初始现金，而是建立利润—产能—订单滚动优化：年度 Q1 批量组合选单、按产品交期预测共享产能、按订单积压扩厂建线、融资期限匹配、应收贴现和终局资产边际价值。验收顺序为先把分配/交付提升到真实范围，再观察权益和发展潜力是否自然上升，最后才比较得分和 VPD。

## 2026-08-11 单企业多模块 Agent 协同校准

新增 `CollaborativeEnterprisePolicy`，由资金、资格、产能、供应履约、订单组合和风险批评六个专业 Agent 共同控制同一家企业。所有模块共享本企业状态和已发布公共信息，订单组合不再逐张独立判断，而是在产品产线、完整批次、交期、库存、现金、固定成本和已承诺订单之间累计占用；最终动作包由财务状态机整体重放后才提交。

三种子结果均为 18 家存续、9 家破产，会计全部平衡，动作拒绝为 0。存续企业平均得分由上一版 276.43 提高到 303.29，平均权益由 211.02 提高到 231.64；每场交付由 22 提高到 39.67，获单后交付率由 22.76% 提高到 41.31%。平均发展潜力为 30.85，与上一版 31 基本持平；每场获单 96，略低于上一版 96.67，因为新版删除了组合容量高估，不再把不可整批交付的订单计入“策略成功”。

与真实 XA 相比，协同版本仍只达到存续平均得分的 19.33%、平均权益的 39.65%、平均获单的 17.11%、平均交付的 7.29% 和交付率的 42.60%。因此本轮已经提高了联合决策质量和履约兑现率，但不能称为接近真实比赛。下一阶段的主要任务是滚动订单—产能—现金优化、异质对手和广告竞争校准、投产时点建模以及由已实现利润驱动的扩产与资格开发。详细模块和指标口径见 `docs/COLLABORATIVE_AGENT_DESIGN.md`，机器结果见 `data/experiments/xa_collaborative_calibration_v3/summary.json`。

## 2026-08-11 协同 Agent v0.3 与可点击赛场

v0.3 不改变 XA 初始现金、成本、订单价格、破产规则或评分公式。它修复了选单冲突后不继续尝试候选、期初到货被重复紧急采购、短贷被人为强制在终局前到期、已获订单生产被风险模块误删，以及年末折旧负权益未及时触发环境破产等问题；策略改为轻资产启动、正常原料滚动采购、订单驱动自动线扩张和五市场双 ISO 的反馈式开发。

三个订单种子均值为：14.33 家存续、12.67 家破产；存续平均得分 490.88、全体平均得分 246.55、存续平均权益 212.83、发展潜力 129.41；每场获单 302.67、交付 235、违约 31.67，获单后交付率 77.65%；平均产品/市场/ISO 为 3.00/4.28/1.67，平均已完成产线 5.52。真实 XA 对应值为 18/9、1569.39、1046.26、584.22、149.67、561、544、11、96.97%、2.89/4.89/1.78 和 8.83。

与 v0.2 相比，获单由 96 提高到 302.67，交付由 39.67 提高到 235，交付率由 41.31% 提高到 77.65%，发展潜力由 30.85 提高到 129.41，存续平均分由 303.29 提高到 490.88。结果已经证明低吞吐主要是 Agent 只按当前产能接单、冲突后没有替补和采购时序错误共同造成，而不是模拟器存在无法产生高分的硬上限。

当前仍不能宣称复现真实经营强度：平均交付只达到真实的 43.20%，权益达到 36.43%，得分达到 31.28%，且破产和违约仍偏多。后续必须使用跨季度联合优化提高产线利用率、订单完整交付和利润保留，并校准会经营到中后期才破产的异质对手。机器结果位于 `data/experiments/xa_collaborative_calibration_v4/summary.json`；浏览器人机/多人赛场见 `docs/CLICKABLE_COMPETITION_PLATFORM.md`。

## 2026-08-11 协同 Agent v0.6

v0.6 保持 XA 的 675 万元初始现金、正式成本、贷款利率、订单价格、税费、折旧、破产条件和得分公式不变。策略侧新增自有/租赁厂房组合、成长型首年两线、库存容量、同产品订单回退、P4/P5 半成品链、到期短贷足额滚动和年末折旧风险预演；校准侧把产品、市场、ISO、产线和自有厂房平均值统一改为存续企业口径。

三个种子均值为：17.33 家存续、9.67 家破产；存续平均得分 811.28、全体平均得分 520.34、权益 337.58、发展潜力 136.71；每场获单 354、交付 273.33、违约 41、获单后交付率 77.23%；存续企业平均产品/市场/ISO 为 3.00/5.00/2.00，完成产线 6.43、自有厂房 2.31。所有企业会计平衡且动作拒绝为 0。机器结果位于 `data/experiments/xa_collaborative_calibration_v8/summary.json`。

相对 v0.3，v0.6 的平均得分由 490.88 提高到 811.28，权益由 212.83 提高到 337.58，获单由 302.67 提高到 354，交付由 235 提高到 273.33，平均完成产线由 5.52 提高到 6.43；存续分布由 14.33/12.67 改善为 17.33/9.67。交付率由 77.65% 略降到 77.23%，原因是新增订单增长快于交付增长，且旧高风险对手早期破产留下悬空订单。

晚期失败压力场不使用旧早死对手，而是让 9 家高风险企业先争单、生产和交付，再从 Y4 起增加租赁线和广告，由状态机自然判定破产。三种子均值为 17.33 家存续、349.33 单获单、299.33 单交付和 85.68% 交付率，证明破产生命周期校准可显著减少悬空订单；代价是强对手竞争使我方存续平均得分降到 647.06、权益降到 273.76。机器结果位于 `data/experiments/xa_late_failure_stress_v2/summary.json`。

因此差距责任已经更清晰：评分模块不是限制，高分企业单场最高分已达到或超过真实存续企业的常见范围；模拟器可以产生真实数量级的存续和中后期破产。剩余群体均值差距主要来自订单吞吐和对手竞争：平均获单仍只有真实的 63.10%，平均交付只有 50.25%，平均产线只有 72.77%。下一阶段需要把年度订单分配拆成可交互阶段，使获单后的企业能在同季度基于实际结果调整生产和融资，并以 4–8 季度搜索替代当前启发式容量预算。

## 2026-08-12 v0.7 复核

v0.7 的默认实现和三种子机器结果位于 `data/experiments/xa_collaborative_calibration_v12/summary.json`。它没有修改 XA 正式规则、初始现金、订单价格或评分公式；主要把潜在新产品单元做成默认关闭的模块化消融开关，并保留六专业 Agent 的联合决策协议。三种子均值与 v0.6 基准一致：17.33/9.67 家存续/破产，存续平均得分 811.28、权益 337.58、发展潜力 136.71，每场获单/交付 354/273.33，获单后交付率 77.23%。

对照实验说明：统一手工线的较慢生产周期无法满足 XA 交期；一次性扩张融资增加负债和破产；无条件预生产和新产品单元虽提高部分获单，却降低平均权益或得分。因此当前正式差距应按真实经营瓶颈解释，而不是调高指标：产线均值 6.43 对 8.83、平均交付 10.12 对 20.15、交付率 77.23% 对 96.97%。下一实现应加入订单分配后的同季度条件经营阶段和跨 4–8 季度的联合搜索。
