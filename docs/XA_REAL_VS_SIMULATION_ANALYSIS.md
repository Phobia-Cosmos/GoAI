# 真实 XA 与模拟比赛结果分析

本报告比较三组数据：真实 XA 省赛赛场、固定 XA 参数且第一年无订单的标准模拟、固定 XA 参数并增加 Y1Q1 初始订单的场景模拟。两场模拟使用相同随机种子 `20260809`、相同第二年至第五年订单和相同编号 Agent 策略，因此它们之间可以近似视为初始订单场景的配对比较；真实 XA 与模拟之间只能做结构和结果分布比较，不能解释为严格因果实验。

真实 XA 中，561/796 个订单有归属，约占 70.5%；544 个已交，另有 11 个违约和 6 个未交。9/27 家企业破产，说明真实参赛者普遍采用更高风险、更高资本占用和更高发展投入的策略。冠军 XA07 的所有者权益为 1050、发展潜力为 261、正式得分为 3791；排名前 3 的得分均超过 2500。

固定模拟中只分配了 46/796 个订单，约占 5.8%，但全部交付且没有破产。所有 Agent 的发展潜力均为 18，主要由本地市场、P1、小厂房和手工线组成，排名几乎完全由少量订单利润和终局权益决定。它验证了全局环境、订单冲突、生产交付、财务状态机、年度三表和终局排名能够闭环运行，但当前现金约束基线明显过于保守，不能复现真实 XA 的策略强度和得分分布。

初始订单场景中，第一次观测对所有 Agent 显示 36 个公共订单；18 家企业各有 1 个私有预分配订单，另外 9 家没有预分配订单。最终 25 个初始订单被分配并全部交付，其中 18 个来自预分配、7 个来自公共池；第二年至第五年又分配并交付 46 个订单。总分配量由 46 提升到 71，平均权益由 273.80 提升到 302.97，平均得分提高 34.43，约提高 10.7%。27 个配对企业中 19 个得分提高、8 个下降。

预分配订单并不等于必然优势。18 家预分配企业平均得分变化为 +18.93，9 家未预分配企业平均变化为 +65.42。未预分配企业可以从 36 个公共订单中选择更匹配利润和产能的订单；预分配企业则必须优先履行随机给定的订单，并失去部分后续择单机会。企业 03 因初始场景得分增加 120.36、排名由第 9 升至第 2；企业 23 得分下降 73.16、排名由第 7 降至第 26。这证明初始订单的价值取决于订单利润、交期、产能匹配和机会成本，而不是“有订单”这一字段本身。

当前结论是：模拟环境已经可以作为全局裁判环境使用，初始订单可见性和随机预分配也已经成为可配置场景；但基线 Agent 还不能代表真实优秀企业。下一阶段应增加扩张型、运营型、融资型和高风险型策略，使产品、市场、ISO、厂房和产线组合产生差异，并让一部分策略在订单压力下破产。随后再用真实 XA 的得分、权益、发展潜力、订单覆盖率和破产率对模拟策略分布做校准，而不是直接调整正式 XA 参数。
