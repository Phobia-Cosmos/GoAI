# XA 企业历史策略重建与模拟

XA 的每个企业工作簿确实包含可以描述企业决策路径的表格，其中 `现金流量表` 是动作主序列，但不能单独承担完整比赛复现。它记录的是已执行且产生现金影响的成功业务，不包含所有失败选单、竞价对手、完整库存流、逐笔应收关联和部分无现金动作。系统因此将现金表与 `研发认证`、`厂房与生产线`、`订单信息`、`银行贷款` 和年度 `三张报表` 合并，形成 27 家企业的历史策略剖面。

## 数据能支持到什么程度

| 数据 | 可确定内容 | 仍缺少内容 |
| --- | --- | --- |
| 现金流量表 | 已执行动作顺序、金额、逐季现金检查点 | 失败动作、部分对象 ID、部分同季阶段顺序 |
| 研发认证 | 产品、市场、ISO 完成时间 | 申请时全部内部状态 |
| 厂房与生产线 | 资产类型、建成时间、当前产品、累计折旧 | 已出售产线和每次转产的精确实例 |
| 订单信息 | 561 个已获订单、544 个历史交付及交付季度 | 全部失败申领、竞价报价和冲突过程 |
| 银行贷款 | 短贷和长贷的借入、期限和结算证据 | 少数额度边界和隐藏审批状态 |
| 三张报表 | 年度库存、应收、固定资产、负债和权益检查点 | 年内三个非年末季度的完整非现金状态 |

所以系统可以做“观察路径重建”，但尚不能只凭一张企业决策表完成无未来信息的裁判级因果复现。

## 四类历史企业策略

27 家企业按实际结果和发展结构分为四类：6 家 `leader_growth`、3 家 `balanced_expansion`、9 家 `conservative_survivor` 和 9 家 `aggressive_failed`。分类用于生成不同的对手行为与压力场景，其中使用了真实终局标签，因此只能用于离线校准，不能直接作为在线 Agent 的输入。

历史策略会按季度重放可识别的融资、研发、市场、ISO、厂房、生产线、采购、广告、生产、交付和应收贴现动作。订单在其真实发布年度才进入环境，不再把最终归属误当成开局分配。XA 现金路径还确认了同季阶段语义：融资可先于到期原料付款，随后才能使用收到的原料生产；一季度产线可在当季完成一批产品；柔性线可以零费用切换合格产品；紧急购买成品按三倍直接成本结算。

## 三种运行模式

| 模式 | 是否读取未来历史 | 用途 | 当前结果 |
| --- | --- | --- | --- |
| `checkpoint_assisted` | 是，读取每季现金、年度权益和实际破产检查点 | 诊断状态机仍遗漏多少转移，不用于 Agent 评分 | 9 家破产、18 家存续与真实一致；重放 512/544 个交付；存续均值权益 584.22；每季现金绝对残差均值 72.77 万元 |
| `conditioned` | 是，读取企业历史动作和真实订单归属，但不注入财务检查点 | 检验已识别动作能否独立维持历史经营路径 | 22 家破产、5 家存续、257 个交付；说明非现金状态和逐笔订单映射仍不足 |
| `competitive` | 读取历史动作偏好，但移除真实订单归属 | 检验历史策略脱离原有对手和订单结果后是否鲁棒 | 当前 27 家全部破产，只完成 7 个交付；这不是对真实 XA 的拟合，而是证明“照搬历史动作”不能替代反馈式策略 |

检查点模式的终局权益和破产标签与真实结果一致，是因为这些字段被作为校准条件，不是模拟器独立预测。它的价值在于量化缺口：历史动作重放后，每季度仍需平均修正约 72.77 万元现金，年度非现金状态也存在明显残差。任何在线反事实实验都禁止启用这些检查点。

## 对我方 Agent 的直接结论

历史路径应被拆成可复用策略组成，例如融资缓冲、资格建设、产能扩张、订单吞吐、库存覆盖和终局资产配置，而不是整条复制。在线比赛中，我方 Agent 只能读取当前规则、我方已知操作、当前私有状态、公共订单和允许购买的对手信息；每次得到新反馈后重新估计对手与未来订单，并从当前季度向前重算。

后续最高优先级是补齐剩余 32 个未重放交付的生产线实例、库存和应收关联，降低不注入检查点的季度状态误差；随后用不会读取未来结果的我方滚动 Agent 对四类随机对手和多个订单种子运行，比较自身得分、名次、破产概率和最坏场景，而不是要求所有模拟企业机械复现历史终局。

可复现入口为 `scripts/run_xa_historical_profiles.py`，产物位于 `data/simulations/xa_historical_profiles_v1/`。所有运行均记录规则版本、策略版本、信息边界、动作、反馈、状态、订单、报表和比较报告。
