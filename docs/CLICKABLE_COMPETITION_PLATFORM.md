# 可点击比赛平台

GoAI 现已提供一个不依赖前端框架的本地 Web 赛场，当前平台版本为 `goai_clickable_competition_v0.4_complete_controls`。浏览器只负责收集点击操作和展示我方可见信息；所有现金、贷款、资格、采购、生产、订单、报表、违约与破产仍由 `FullCompetitionArena` 和 `FullFinancialDynamics` 统一结算，前端不能直接修改状态。

## 启动

```bash
cd /home/undefined/Desktop/GoAI
PYTHONPATH=src /home/undefined/Disk/python-envs/goai-py312/bin/python scripts/run_web_platform.py --host 127.0.0.1 --port 8765
```

浏览器访问 `http://127.0.0.1:8765`。需要让同一局域网的其他选手参加时使用 `--host 0.0.0.0`，并把服务器 IP、端口和页面生成的比赛加入码发给选手。

## 已实现的比赛方式

- 单人对 Agent：创建比赛时设置一个人类席位，其余企业由所选 Bot 策略控制。
- 多人对 Agent：设置多个但少于企业总数的人类席位，玩家凭加入码进入，其余席位由 Bot 补齐。
- 纯用户比赛：人类席位等于企业数量。
- 纯 Agent 训练场：页面允许人类席位为 0，可逐阶段推进，也可直接运行至终局。
- 对手强度：可选择聚合异质对手、晚期扩张压力对手、协同 Agent、保守基线或启发式对手；晚期扩张压力对手会先正常经营，再由环境根据后期租赁产能和广告扩张判定是否破产。
- 双阶段同步结算：同一季度先等待所有人类玩家提交经营与订单申领，裁判统一运行 Bot 并处理订单冲突；每位玩家随后看到本企业的实际获单，再提交融资、扩产、采购、生产和交付。第二阶段也等待全员提交后才执行违约、财务结算并推进季度。其他玩家的私有现金、库存、贷款和动作不会进入我方观察。

## 可点击动作

界面覆盖短贷、长贷、应收贴现、产品/市场/ISO 开发、厂房购买/租赁/出售、产线建设/转产/出售、普通原料采购、紧急原料与成品采购、生产、订单交付、广告、选单、竞单、组合申领（含同产品且交期不早于主订单的回退候选）和规则允许的信息购买。生产动作可明确选择产线，柔性线会按当前资格显示可生产产品；竞单可编辑报价，短贷期限按季度、长贷期限按年填写。空动作包等价于保持。用户也可以让六专业 Agent v0.9 生成一个联合动作包，再人工删除、增加或修改后提交；推荐 Agent 会按状态机真实安装/生产时序计算可执行容量，并允许一个满足资金和权益门槛的有界 P1–P3 新产品单元。

进入获单后履约阶段后，广告、资格开发和订单申领等非法动作会在页面禁用，服务端也会拒绝绕过界面的非法提交。用户可以返回大厅并清除本地比赛令牌；XA 信息购买按实际事件证据使用 5 万元/次，购买结果只对购买企业可见。

v0.9 在三个 XA 经验订单种子上的均值为 497.67 单获单、464.33 单交付、93.26% 获单后交付率、1536.90 存续平均得分和 619.36 万元存续平均权益。真实 XA 对应为 561、544、96.97%、1569.39 和 584.22。评分和权益已进入真实数量级，但获单和交付绝对规模仍偏低；网页平台应被理解为可运行的训练赛与 Agent 评测环境，而不是声称精确复刻真实比赛的每个终局统计。

比赛结束后页面可下载完整 JSON，内容包括固定规则、796 条无终局标签的经验形状订单、20 季结算记录、40 个阶段级动作与反馈、订单分配日志、终局状态、报表、破产和排名。该导出用于复盘、VPD 验收和后续 Agent 训练，不会在比赛进行中泄露其他企业的私有状态。

## 接口

- `GET /api/health`：服务健康状态。
- `GET /api/catalog`：企业数、人类席位、Bot 类型和规则包目录。
- `POST /api/matches`：创建比赛。
- `POST /api/matches/{id}/join`：加入人类席位。
- `POST /api/matches/{id}/start`：开始比赛。
- `GET /api/matches/{id}`：取得公开状态；携带玩家令牌时同时返回该玩家的私有观察。
- `POST /api/matches/{id}/recommend`：为我方企业生成六专业 Agent 联合建议。
- `POST /api/matches/{id}/submit`：提交我方本季度动作包。
- `POST /api/matches/{id}/advance`：推进无人类玩家的 Agent 比赛。
- `POST /api/matches/{id}/run`：将无人类玩家的 Agent 比赛运行至终局。
- `GET /api/matches/{id}/export`：终局后导出完整记录。

## 当前部署边界

这是可供训练赛和局域网比赛使用的 MVP，不是公网生产服务。比赛会话和令牌当前保存在服务器内存中，进程重启后失效；尚未接入数据库、账户密码、TLS、反向代理、限流和断线恢复。若要公开部署，下一阶段应增加持久化会话、正式身份认证、房主权限、赛程管理、服务端日志签名和容器化部署，不能直接把当前开发服务器暴露到互联网。
